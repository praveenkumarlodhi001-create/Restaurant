# Noderra Restaurant Website Demo

Premium restaurant website concept built with plain HTML, CSS and JavaScript. No framework or build process required.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome or another modern browser.
3. Internet access is needed for Google Fonts and remote Unsplash food/interior photos.

## Included
- Responsive restaurant landing page
- Animated hero and scroll reveals
- Menu category filters
- Sample menu cards and pricing
- Reservation request form that opens the visitor's email app
- Opening hours, location and contact sections
- Supplied Noderra logo watermark in hero, experience and footer
- Reduced-motion accessibility support

## Before client delivery
- Replace sample menu items/prices, hours, address and contact details with verified client information.
- Update `BOOKING_EMAIL` in `js/main.js` and `hello@example.com` in `index.html`.
- The reservation form uses `mailto:` and does not store bookings. Connect a real reservation service or backend for production.
- Food photos are remote Unsplash URLs and require internet. Replace with client-approved images when available.
- The displayed restaurant identity is intentionally generic so the design can be customized for a buyer.
